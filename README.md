# Matched molecular pairs visualisation

## Description
An Java GUI application to extract matched molecular pairs from an sdf file and visualise them as a matrix or a graph or a Kanban-like card board
To obtain matched molecular pairs, it is using an MCS (maximum common substructure) algorithm as implemented by the CDK chemistry package which is more accurate but slower O(n2) compared to the Hussain-Rea algorithm (Journal of Chemical Information and Modeling 2010 50 (3), 339-348
DOI: 10.1021/ci900450m)
